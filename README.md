# فقّاسة · FOREGG

نظام خاص للفقاسات: لكل مستخدم 3 فقاسات، كل وحدة بإعدادها (يدوي أو أوتوماتيك، نوع البيض، اليوم الحالي).

- حرارة ورطوبة وتقليب **يوم بيوم** لـ 14 نوع بيض (دجاج، دجاج عربي، زينة، بط، مسكوفي، وز، رومي، طاووس، حبشي، دراج، حجل، سمان، حمام، نعام).
- **بيضة ثلاثية الأبعاد تحت ضوء الفحص**: الشعيرات الدموية، الجنين، العين، الكيس الهوائي، والنقر، تكبر حسب اليوم. تنسحب بالإصبع حتى تدور.
- أول 3 أيام وآخر 3 أيام بلا تقليب (يتغير من الإعدادات).
- إشعارات: أوقات التقليب، ملخص الصباح، بداية الإغلاق.
- يتثبت على الأندرويد كتطبيق (PWA) ويشتغل بدون إنترنت.
- لوحة مدير تعرض كل المستخدمين وبأي يوم وصلوا. كلمات المرور مشفّرة (bcrypt) وما تنعرض.

## التشغيل محلياً

```bash
npx http-server@14.1.1 . -p 5173 -c-1
```

## البيانات

Supabase (جداول `foregg_users`، `foregg_tokens`، `foregg_incubators`). الوصول فقط عبر دوال `foregg_*`.
لجعل حساب مدير:

```sql
update public.foregg_users set is_admin = true where username = 'اسم_المستخدم';
```
